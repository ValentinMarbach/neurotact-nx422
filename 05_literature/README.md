# 05 — Literature

- `references.bib` — **the** bibliography for report and slides. Key format: `firstauthorYEAR` (e.g. `flesher2021`).
- `notes/` — one Markdown note per important paper (`notes/flesher2021.md`, template `notes/_TEMPLATE.md`).
  Claudes read the notes first and open the PDF only when needed.
- `physiologie/` — papers sorted by theme (index: `physiologie/00_INDEX.md`); `08_Partie_LSE1/` = papers behind LSE1.
- `references_initiales/` — first papers found at project start.

Add a paper with `/add-paper`.
